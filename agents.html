Deckbook × Агенты

Как рутины, задачи и документы замыкаются в самоходный цикл. Данные — из реальных расписаний и команд. Пунктир и метка план — решено и заведено задачами, но ещё не работает.

Сигнал→ Дневной лог logs/→ Задача в Deckbook→ fix-task: код → PR → CI → merge→ done + отчёт→ ночной sync-state → state/

Словарь из CONTEXT.md — агенты обязаны говорить этими терминами и не съезжать на синонимы.

todo→in_progress→done илиcancelled ·needs_human— упёрлась в ответ владельца приоритет: high / normal / low · normal нигде не показывается

Глобальные рутины: логика в ~/.claude/commands/deckbook/*.md, крон только вызывает слэш-команду. Все пишут секцию в дневной лог и заводят задачи на проблемы — сами ничего не чинят (кроме fix-task). Пунктирные карточки — в плане, задачи заведены.

Дерево документов проекта в Deckbook (структура SecScanner). Кликай по папкам.

state/«как есть сейчас», без истории — перезаписывается ночным синком
spec/что система делает
data-model модель данных
flows/ флоу и экраны
checks проверки сканера
product/рынок и продукт
metrics события аналитики и определения метрик
pricing цены и тарифы
positioning позиционирование, конкуренты — сюда пишет check-seo
design/эталон для дизайн-аудита
tokens цвета, типографика, отступы
patterns повторяющиеся паттерны UI
components компоненты
voice-and-tone голос и тон текстов
arch карта архитектуры + решения D-NNNN
hypotheses ставки: evidence, статус, Closed-таблица с вердиктами
experiments E-NNN, green-light метрики, Завершённые
logs/дневные логи YYYY-MM-DD — общая лента всех рутин за день
2026-08-02 секции: ## Логи (SigNoz) · ## Аналитика · ## Изменения · ## SEO · ## Security · ## Sync …
tasks формат задач: ссылка на лог + критерии приёмки
README пороги создания задач: 3+ лога подряд или 2+ независимых источника
_archive/ логи старше 4 недель
Правило потока: рутины пишут только в logs/ (сырьё за день). Ночью sync-state разбирает вчерашний лог и обновляет state/ — так state остаётся снимком «сейчас», а не свалкой истории. В репозитории кода живут только CONTEXT.md и docs/adr/.
