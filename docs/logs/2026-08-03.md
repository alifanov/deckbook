# 2026-08-03

## Изменения

- Быстрый перевод статуса на странице задачи — статус в шапке стал набором кнопок, клик сразу меняет статус без раскрытия «Изменить»; дублирующий селект убран. PR https://github.com/alifanov/deckbook/pull/21
- Новая задача из интерфейса назначается на первого агента — раньше UI-задача создавалась ничьей и не попадала ни в один `my_tasks`; теперь исполнителем становится первый действующий агент проекта (отозванные пропускаются, без агентов — как было). PR https://github.com/alifanov/deckbook/pull/22
- Плитки статусов на странице проекта стали кликабельными фильтрами — клик отбирает задачи по статусу, повторный клик снимает отбор; дропдаун «Любой статус» из панели фильтров убран. PR https://github.com/alifanov/deckbook/pull/23
- Сортировка дерева задач по приоритету — внутри одного статуса важное сверху, неважное снизу (high → normal → low), при равном приоритете по времени создания. PR https://github.com/alifanov/deckbook/pull/24
- Список проектов: действия «Переименовать» и «Удалить» на карточке стали иконками без текста (подпись — в `title`/`aria-label`), кнопка «Создать проект» стала тише — мелкий шрифт и приглушённый цвет вместо акцентной заливки. PR https://github.com/alifanov/deckbook/pull/25

## Sync

Обновлено:

- `state/spec/inventory` — экран проекта: плитки статусов работают фильтром (дропдаун «Любой статус» убран); экран задачи: статус меняется кнопками в шапке; список проектов: действия карточки — иконки; добавлено правило порядка в дереве задач (статус → приоритет → время создания).
- `state/spec/flows/agent-loop` — откуда у задачи исполнитель: задача из UI автоматически уходит первому действующему агенту проекта, иначе она ничья и не видна в `my_tasks`.
- `state/design/tokens` — правило веса действий: второстепенные действия иконкой без подписи, служебные кнопки без акцентной заливки.

Задач не создано: в логе только задеплоенные изменения, наблюдений с проблемами нет.

Не трогали: `state/arch` — форма системы и границы слоёв не изменились, нового ограничивающего решения нет; `state/hypotheses` — данных за или против H-001…H-003 в логе не появилось; `state/product/*` — фактов о продукте, ценах и каналах в логе нет.
