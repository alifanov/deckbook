```
Invalid `prisma.document.findUnique()` invocation: where: { id: undefined }

```

Причина в коде, не в данных: `src/mcp/server.ts:74` отдаёт `inputSchema` клиенту, но `required`

`required: ["documentId"]` объявлен, `args.documentId === undefined` доходит до Prisma.
Дыра общая для всех 19 инструментов. Побочно: в ответ агенту утекает дамп `DocumentWhereInput`
со всеми полями модели.

Порог пройден по правилу «2+ независимых источника»: лог SigNoz + чтение кода.
