# Шаблонов задач нет

Шаблон был заготовкой дерева задач с флагом `isTemplate`: агент вызывал
`list_templates` и `apply_template`, поддерево копировалось в проект. Мы
убрали его целиком — вместе с полем, инструментами, страницей и данными.

Заготовка нужна тому, кто не знает, из каких шагов состоит работа. Агент
это знает: попросить его создать задачи на тесты, билд и деплой дешевле,
чем держать ради этого отдельное состояние в базе. Взамен не появилось
ничего — типовое дерево строится обычным `create_task`.

## Consequences

- Ушло условие `isTemplate = false` из каждой выборки задач — плата,
  которую ADR-0001 называл главной ценой одной таблицы.
- `Task.projectId` стал обязательным: глобальный шаблон был единственным,
  что жило вне проекта. Правило «всё принадлежит ровно одному проекту»
  теперь держит схема, а не договорённость.
- Миграция удаляет существующие деревья шаблонов безвозвратно. На проде
  их не было ни одного; дамп базы снят до выката.
