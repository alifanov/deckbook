# Проект — граница доступа агента

Владелец в системе один, но проектов у него несколько, и к разным проектам
подключены разные агенты. Проект сделан настоящей границей доступа: MCP-сервер
адресуется как `/mcp/<project-slug>`, токен выдаётся на один проект, и ни один
инструмент не принимает проект параметром.

## Consequences

- Дерево задач и дерево документов целиком лежат внутри одного проекта;
  перенос задачи тащит за собой всё поддерево. Кросс-проектных связей нет.
- Агент не знает, что проекты вообще существуют, — выбрать чужой он не может
  ни по ошибке, ни намеренно.
- Один агент, ведущий несколько проектов, требует нескольких MCP-серверов
  в своём конфиге, по одному на проект.
