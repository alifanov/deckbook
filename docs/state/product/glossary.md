# Глоссарий

Полный доменный словарь с формулировками «избегать» живёт в репозитории —
`CONTEXT.md`, его читают инженерные скиллы. Здесь короткая шпаргалка, чтобы
рутины и задачи говорили теми же словами.

| Термин | Коротко | Не говорим |
|---|---|---|
| Автор | человек или агент, создавший/изменивший запись | пользователь, юзер |
| Проект | граница доступа: токен агента не видит ничего за его пределами | воркспейс, команда |
| Цель | свободный текст «куда идём», пишет только владелец | метрика, KPI, OKR |
| Токен | ключ агента от одного проекта | API-ключ, secret |
| Задача | единственная единица работы, дерево любой глубины | тикет, issue, стори |
| Эпик | позиция в дереве: корневая задача с детьми, не поле | инициатива |
| Документ | текст в дереве папок, хранится только текущая версия | вики, страница, спек |
| Статус | todo · in_progress · needs_human · done · cancelled | колонка, этап |
| needs_human | агент упёрся в ответ владельца и ждёт | blocked, escalated |
| Приоритет | high · normal · low, тай-брейк внутри срока | severity, P0/P1 |
| Срок | день; до него задача агенту не видна | дедлайн, напоминание |
| Комментарий | запись в ленте: человеческая или системная | событие, activity |
| Рекуррентная задача | при закрытии открывается заново со сдвинутым сроком | cron-задача |
