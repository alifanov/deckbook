# Продукт

Личный self-hosted трекер задач, у которого MCP — основной интерфейс: задачи создают
и меняют AI-агенты наравне с владельцем. Код, ветки и пул-реквесты остаются на GitHub.

**Для кого**: один владелец и его агенты. Команд, ролей и приглашений нет.

**Что внутри**: задачи (дерево любой глубины, пять статусов, приоритет, срок,
повторение), документы (дерево папок, только текущая версия), проекты (граница
доступа), токены агентов.

**Чего сознательно нет**: типов задач и шаблонов (D-0001, D-0006), истории версий
(D-0002), метрик и OKR у проекта — только свободная цель (D-0007), командной работы.

**Догфудинг**: Deckbook ведёт собственные задачи и документы в себе же — этот
Deckbook и есть проект `deckbook`.
