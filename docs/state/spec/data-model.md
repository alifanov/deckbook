# Модель данных

Источник истины — `prisma/schema.prisma`; здесь смысл, а не поля один в один.

| Модель | Смысл | Ключевое |
|---|---|---|
| `Owner` | Владелец. Строка ровно одна | `passwordHash` из env при первом входе; `sessionEpoch` растёт на выходе и гасит старые cookie |
| `Project` | Граница доступа агента | `slug` уникален; `goal` — свободный текст, пишет только владелец (D-0007); `localPath` — путь к локальному чекауту, его подставляет диплинк «Исправить» |
| `Token` | Ключ агента от одного проекта | хранится хешем; `revokedAt` вместо удаления; `lastUsedAt` |
| `Task` | Единственная единица работы, дерево любой глубины | `parentId` (эпик = корень с детьми), `status`, `priority`, `dueAt` (день, без времени), `recurrence` в днях |
| `Comment` | Запись в ленте задачи | `kind`: human или system; готовый текст, отдельной истории изменений нет (D-0002) |
| `Document` | Текст в дереве папок проекта | только текущая версия; с задачами не связан |

Статусы задачи: `todo`, `in_progress`, `needs_human`, `done`, `cancelled`.
Приоритет: `low`, `normal`, `high` — порядок объявления enum и есть порядок сортировки.

Исполнитель взаимоисключим: `assigneeTokenId` (агент) либо `assignedToOwner`.
Оба пусты — задача ничья и не попадает ни в один `my_tasks` (но видна в `project_tasks`).

Миграции: `prisma/migrations/` (8, последняя `20260805000000_project_local_path`),
только `migrate deploy` — `db push` запрещён (D-0005).
