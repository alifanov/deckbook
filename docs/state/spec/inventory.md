# Экраны

Веб-интерфейс владельца. Всё под cookie-сессией, кроме `/login`.

| Путь | Экран | Что делает |
|---|---|---|
| `/login` | Вход | пароль владельца из `OWNER_PASSWORD`; 5 неудач подряд с одного адреса закрывают вход на 15 минут |
| `/` | Проекты | список проектов, цель проекта; мини-график бэклога за 7 дней рядом с названием (накопленная разница «заведено минус закрыто»: вверх и красным — растёт, вниз и зелёным — разгребается; шкала у каждой карточки своя); «Переименовать» и «Удалить» — иконки без подписи (подпись в `title`/`aria-label`) |
| `/my-tasks` | Мои задачи | задачи владельца + все `needs_human` независимо от исполнителя; по умолчанию скрыты задачи с ненаступившим сроком, галочка «Показывать отложенные» (`?future=1`) возвращает их, счётчик в хидере считает то же, что показано по умолчанию |
| `/projects/[slug]` | Проект | дерево задач; плитки статусов — это и фильтр: клик отбирает задачи по статусу, повторный клик снимает; закрытые задачи по умолчанию скрыты, галочка «Показывать выполненные» (`?closed=1`) возвращает их, а выбранный плиткой статус показывает своё независимо от галочки; фильтр по исполнителю (владелец или любой токен, включая отозванные); график «Заведено и закрыто» по дням; отложенные задачи здесь видны всегда; «Цель» и «Папка» (`localPath`) правятся одной формой (`intent=meta`), папку берёт кнопка «Исправить» на экране задачи |
| `/projects/[slug]/tasks/[id]` | Задача | чтение: поля, описание в Markdown, лента комментариев, подзадачи; статус меняется сегментом в один клик без подтверждения; кнопка «Исправить» — диплинк `claude://code/new?q=/deckbook:fix-task <id>&folder=<localPath>`, открывает задачу в Claude Code (без «Папки» проекта уходит без `folder`, десктоп откроет папку последней сессии) |
| `/projects/[slug]/tasks/[id]?edit=1` | Задача · правка | отдельный режим страницы, а не панель поверх: заголовок, статус, приоритет, срок, исполнитель, описание — одной формой, применяются по «Сохранить», «Отмена» возвращает к чтению; здесь же «Удалить задачу» (с подтверждением, вместе с подзадачами и лентой) |
| `/projects/[slug]/documents` | Документы | дерево папок |
| `/projects/[slug]/documents/[id]` | Документ | чтение и правка, рендер Markdown |
| `/projects/[slug]/tokens` | Токены | выпуск и отзыв токенов агентов |

Порядок в дереве задач: сначала по статусу, внутри статуса — по приоритету
(high → normal → low), при равном приоритете — по времени создания.

API: `/api/tasks`, `/api/documents`, `/api/projects`, `/api/tokens`, `/api/session`.
MCP: `/mcp/[project]` — единственная точка для агентов.
