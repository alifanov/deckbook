# Токены и визуальный язык

Стиль — «тихий лист»: светлая бумага, иерархия задаётся подложкой, а не рамками.
Только светлая тема (`color-scheme: light`). Источник — `src/app/globals.css`,
переменные в `:root`.

| Группа | Переменные | Значения |
|---|---|---|
| Фон | `--bg` · `--panel` | `#f5f2ec` · `#fbfaf7` |
| Линии | `--line` · `--rule` · `--field` | `#eae5db` · `#f0ece3` · `#e5dfd3` |
| Текст | `--text` · `--ink` · `--muted` · `--dim` | `#2c2a26` · `#38352f` · `#918879` · `#a89f90` |
| Акцент | `--accent` · `--accent-ink` · `--accent-bg` | `#5d7a42` · `#4f6a37` · `#f4f7ee` |
| Статус-точки | `--dot` · `--dot-done` · `--dot-line` | `#7d9a5b` · `#b9c9a6` · `#cfc7b8` |
| Служебные | `--live` · `--danger` · `--danger-bg` · `--danger-line` | `#33668a` · `#a8574f` · `#fbf1ef` · `#edd9d4` |

Правила: цвет берём переменной, не литералом; разделение блоков — подложка `--panel`
и тонкая `--rule`, а не рамка; акцент зелёный и один — второго акцентного цвета не заводим;
красный только для необратимого (`--danger`).

Вес действий: второстепенные действия карточки — иконка без текстовой подписи,
подпись живёт в `title`/`aria-label`; акцентной заливки у служебных кнопок нет —
мелкий приглушённый текст вместо неё.
