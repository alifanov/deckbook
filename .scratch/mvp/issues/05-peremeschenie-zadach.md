# 05 — Перемещение задач

**What to build:** Владелец переносит задачу под другого родителя или вытаскивает
вложенную задачу в корень проекта. Поддерево всегда едет следом — дерево не рвётся
и не оставляет сирот.

Перемещение — единственная операция, способная создать цикл или разорвать
границу проекта, поэтому обе проверки живут здесь и должны быть доказаны тестами.

**Blocked by:** 04 — Задачи: дерево и создание.

**Status:** ready-for-agent

- [ ] Владелец переносит задачу под другого родителя внутри проекта
- [ ] Владелец делает вложенную задачу корневой
- [ ] При переносе всё поддерево перемещается вместе с задачей
- [ ] Попытка перенести задачу внутрь её собственного поддерева отвергается
- [ ] Попытка перенести задачу в другой проект отвергается
- [ ] Агент перемещает задачу через MCP с теми же правилами
