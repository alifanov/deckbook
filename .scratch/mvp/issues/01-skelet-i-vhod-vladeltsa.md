# 01 — Скелет и вход владельца

**What to build:** Владелец поднимает систему одной командой `docker compose up`,
открывает её в браузере, вводит пароль и попадает на пустую главную страницу.
Пароль задаётся переменной окружения при первом запуске. Сессия переживает
перезагрузку страницы; выход закрывает доступ.

Это первый тикет в пустом репозитории, поэтому он несёт и каркас: Next.js
App Router на TypeScript, Prisma поверх Postgres, `docker-compose.yml` без
внешних сервисов, и прогон тестов доменного слоя против настоящей базы —
той самой инфраструктуры тестов, на которую опираются все следующие тикеты.

**Blocked by:** None — can start immediately.

**Status:** done
