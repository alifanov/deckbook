# 01 — Скелет и вход владельца

**What to build:** Владелец поднимает систему одной командой `docker compose up`,
открывает её в браузере, вводит пароль и попадает на пустую главную страницу.
Пароль задаётся переменной окружения при первом запуске. Сессия переживает
перезагрузку страницы; выход закрывает доступ.

Это первый тикет в пустом репозитории, поэтому он несёт и каркас: Next.js
App Router на TypeScript, Prisma поверх Postgres, `docker-compose.yml` без
внешних сервисов, и прогон тестов доменного слоя против настоящей базы —
той самой инфраструктуры тестов, на которую опираются все следующие тикеты.

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] `docker compose up` поднимает приложение и Postgres, больше ничего не требуется
- [ ] Пароль читается из переменной окружения и хранится хешем, а не в открытом виде
- [ ] Верный пароль создаёт сессию в подписанной httpOnly-cookie
- [ ] Неверный пароль не создаёт сессию и сообщает об ошибке
- [ ] Любая страница, кроме страницы входа, без сессии ведёт на вход
- [ ] Выход завершает сессию, после него защищённые страницы снова недоступны
- [ ] Тесты доменного слоя запускаются одной командой против настоящего Postgres,
      каждый тест видит чистое состояние
- [ ] Потребление памяти под простоем измерено и записано — это первая проверка
      потолка в 4 ГБ, о которой говорит спека
