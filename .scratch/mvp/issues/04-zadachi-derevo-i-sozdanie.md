# 04 — Задачи: дерево и создание

**What to build:** Владелец создаёт задачи в проекте, даёт им заголовок и
описание, добавляет подзадачи произвольной глубины и видит дерево целиком,
сворачивая и разворачивая ветки. То же самое умеет агент через MCP: создать
задачу, создать подзадачу, прочитать задачу вместе с её поддеревом.

Задача — единственная единица работы (ADR-0001): отдельных типов нет, эпик это
просто задача без родителя, у которой есть дети. В каждой записи видно, кто её
создал — владелец или конкретный агент.

Дерево не может выйти за пределы проекта и не может замкнуться в цикл; попытка
получает внятный отказ, а не молчаливую правку.

**Blocked by:** 03 — Токены и MCP-эндпоинт с изоляцией.

**Status:** ready-for-agent

- [ ] Владелец создаёт задачу с заголовком и описанием
- [ ] Владелец создаёт подзадачу у существующей задачи
- [ ] Вложенность не ограничена фиксированной глубиной
- [ ] UI показывает дерево задач проекта со сворачиванием и разворачиванием веток
- [ ] Задачи верхнего уровня, у которых есть дети, видны как эпики — без отдельного
      поля и отдельной сущности
- [ ] Владелец удаляет задачу вместе с её поддеревом
- [ ] Агент создаёт задачу и подзадачу через MCP
- [ ] Агент читает задачу вместе с поддеревом через MCP
- [ ] У MCP-инструментов нет параметра проекта — проект берётся из адреса и токена
- [ ] В каждой задаче видно, создал её владелец или агент, и какой именно
- [ ] Родитель и ребёнок всегда принадлежат одному проекту; попытка связать задачи
      разных проектов отвергается
- [ ] Задача не может стать потомком самой себя
