# 12 — Импорт текстовых файлов

**What to build:** Владелец загружает `.md` или `.txt` с диска и получает документ
в дереве проекта — можно одним файлом, можно пачкой, чтобы перенести целую папку
заметок за раз. Имя файла становится названием документа, содержимое — текстом.

Загрузка означает импорт текста, а не хранение файла: файл читается и
выбрасывается. Файлового хранилища, тома на диске и S3 в системе не появляется —
всё остаётся в Postgres, и бэкапом остаётся один дамп базы.

**Blocked by:** 11 — Документы: перемещение, переименование, удаление.

**Status:** ready-for-agent

- [ ] Владелец загружает текстовый файл и получает документ в выбранной папке
- [ ] Владелец загружает несколько файлов за один раз
- [ ] Название документа берётся из имени файла без расширения
- [ ] Содержимое файла становится текстом документа
- [ ] Файл нетекстового типа отвергается с понятным сообщением
- [ ] Файл сверх разумного предела размера отвергается с понятным сообщением
- [ ] Загруженный файл нигде не сохраняется — на диске и в томах ничего не появляется
- [ ] Загрузка в папку, принадлежащую другому проекту, невозможна
