# 02 — Проекты

**What to build:** Владелец создаёт проекты, видит их список на главной,
переименовывает и удаляет. Проект — это будущая граница доступа агента
(ADR-0003), поэтому у него есть человекочитаемый идентификатор, по которому
позже будет адресоваться MCP-сервер.

Удаление проекта уносит всё его содержимое; на этом этапе содержимого ещё нет,
но поведение задаётся сразу, чтобы следующие тикеты добавляли к нему сущности,
а не переизобретали каскад.

**Blocked by:** 01 — Скелет и вход владельца.

**Status:** ready-for-agent

- [ ] Владелец создаёт проект, указав название
- [ ] У проекта есть короткий идентификатор для адреса, уникальный среди проектов
- [ ] Главная показывает список проектов владельца
- [ ] Владелец переименовывает проект, идентификатор для адреса при этом не меняется
- [ ] Владелец удаляет проект, подтвердив действие
- [ ] Удаление проекта каскадом уносит всё, что к нему принадлежит
- [ ] Проекты доступны только под сессией владельца
