# 07 — Комментарии и системные записи

**What to build:** У задачи появляется лента записей в хронологическом порядке.
Владелец и агент пишут в неё комментарии; система сама добавляет туда записи о том,
что с задачей произошло — смена статуса, назначение, перемещение, правка заголовка
или описания. В каждой записи видно автора и видно, написал её человек, агент или
система.

Отдельной истории изменений в системе не существует (ADR-0002): эта лента и есть
единственный след того, что происходило. Системные записи хранятся готовым текстом,
структуры «поле, было, стало» нет — это осознанное ограничение, а не упущение.

**Blocked by:** 05 — Перемещение задач; 06 — Статусы и назначение на агента.

**Status:** ready-for-agent

- [ ] Владелец пишет комментарий к задаче
- [ ] Агент пишет комментарий к задаче через MCP
- [ ] Агент читает ленту задачи через MCP
- [ ] UI показывает ленту задачи в хронологическом порядке
- [ ] Смена статуса порождает системную запись
- [ ] Назначение и снятие назначения порождают системную запись
- [ ] Перемещение задачи порождает системную запись
- [ ] Правка заголовка или описания порождает системную запись
- [ ] В каждой записи виден автор: владелец или конкретный агент
- [ ] Системная запись визуально отличается от написанной человеком или агентом
- [ ] Удаление задачи уносит её ленту
